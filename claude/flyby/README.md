# Flyby 比較器

上傳多個 GPX / FIT / TCX（可為 `.gz`）活動檔，在同一張地圖上重播並比較速度。純靜態網站，檔案只在瀏覽器裡解析，不會上傳。

## 部署

把這個資料夾（`index.html`、`app.js`、`parsers.js`、`style.css`）放到任何靜態伺服器即可，例如：

```sh
python3 -m http.server 8000   # 然後打開 http://localhost:8000
```

Leaflet 從 unpkg 載入、底圖使用 OpenStreetMap 圖磚，所以瀏覽器需要能連網。

## 功能

- **自動對齊**
  - 對齊共同起點：在參考活動上找一個所有活動都經過、且每個人都最早到達的點（讓「誰騎最遠才到這裡」最小），讓大家在 T = 0 時同時通過該點；距離也從這裡開始算。適合同一路線不同天的比較，起點不同的環線也可以。
  - 同時按下開始：每個活動從各自的第一個紀錄點開始。
  - 實際時間：依真實時鐘重播，適合同一場團騎。
- **手動平移**：每個活動有一條拉桿（±最長活動時間）和秒數輸入框，疊加在自動對齊之上。
- **排行榜**：即時距離、落後時間（落後者要多久才能到領先者現在的位置）、時速（10 秒平均）。
- **時間差圖**：以距離為橫軸，畫出每個活動相對參考活動快／慢幾秒。
- **海拔剖面**：參考活動的海拔與每個人的目前位置；點兩張圖都能跳到該距離。
